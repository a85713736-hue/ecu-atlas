# Интерактивный атлас ЭБУ

Независимый проект каталога электронных блоков управления, с первоочередным фокусом на китайских автомобилях.

Стек: Next.js, PostgreSQL/Prisma, Three.js, Python-агенты.

## Запуск

1. `npm install`
2. Скопировать `.env.example` в `.env` и указать действующую строку подключения `DATABASE_URL`.
3. `npx prisma db push`
4. `npm run dev`

Это начальный прототип; 3D визуализация условная, не подтверждает точную геометрию ЭБУ. Агентные роли пока не осуществляют автономный сбор информации. Пин-ауты и Boot-точки публикуются только после проверки источников.
