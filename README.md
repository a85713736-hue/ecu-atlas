# Интерактивный атлас ЭБУ

Независимый проект каталога электронных блоков управления, с первоочередным фокусом на китайских автомобилях.

Стек: Next.js, PostgreSQL/Prisma, Three.js, Python-агенты.

## Запуск

1. `npm install`
2. Скопировать `.env.example` в `.env` и указать действующую строку подключения `DATABASE_URL`.
3. `npx prisma db push`
4. `npm run dev`

Это начальный прототип; 3D визуализация условная, не подтверждает точную геометрию ЭБУ. Агентные роли пока не осуществляют автономный сбор информации. Пин-ауты и Boot-точки публикуются только после проверки источников.

## Агент-исследователь

Реальный поиск через Brave Search API: `agents/researcher.py`. По шести категориям собирает ссылки и фрагменты страниц, сохраняет JSON для ручной проверки. Не выдаёт поисковые фрагменты за доказанную распиновку и не пишет результаты напрямую в базу.

Для запуска из GitHub: Settings → Secrets and variables → Actions → New repository secret → `BRAVE_SEARCH_API_KEY`. Получить API-ключ у Brave Search API, предварительно проверить тариф и лимиты. Далее Actions → ECU research agent → Run workflow; ввести идентификатор ЭБУ. Результат скачать из Artifacts выполненного workflow.

Есть ежедневный запуск по UTC; **без API-ключа workflow завершится ошибкой**, поэтому пока не является автономно работающим агентом. Для полноценной автоматической публикации нужны извлечение полных документов, верификация источников, безопасная очередь согласования и защищённая запись в PostgreSQL.
